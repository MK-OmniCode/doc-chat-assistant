# Doc Chat Assistant

Build a customer support chatbot web app using Next.js and Tailwind CSS. The app should let a user upload a PDF or paste FAQ text, then chat with an AI that answers questions ONLY based on that uploaded content (RAG-style). Use the Anthropic API (Claude) for the chat responses. Include: a clean chat UI, a file upload panel, loading states, and a way to clear/reset the conversation. Keep the code in a single well-organized project with clear comments so I can explain it in an interview.
